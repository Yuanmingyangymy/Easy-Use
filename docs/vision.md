# Easy-Use Vision

Easy-Use exists because many everyday computer tasks deserve tools that are smaller, calmer, and easier to trust.

People often need to do one simple thing: move a file, resize an image, extract text, clean a PDF, convert a snippet, or share something across devices. Too often the available software is bloated, account-gated, filled with tracking, or built around a cloud workflow that the user never asked for.

Easy-Use takes the opposite direction:

- Solve one clear pain at a time.
- Make the default path obvious.
- Keep tools fast and understandable.
- Prefer local-first workflows where they make sense.
- Avoid accounts unless they are truly necessary.
- Keep safety and privacy claims honest.
- Make the source code useful to users and maintainers.

The project is not trying to become a giant productivity suite. It is a place to steadily collect small tools that feel carefully made.

The first tool, DropLite, focuses on one common problem: quickly sending text, images, and files from a phone browser to a desktop over the local network.
